# Quantium Data Analytics Virtual Experience

This repository contains the completed tasks from the **Quantium Data Analytics Virtual Experience Program** hosted on Forage. The project simulates a real-world data consulting engagement, focusing on retail transaction analysis and strategic business recommendations.

## 🚀 Project Overview
The objective was to analyze retail transaction data to identify high-value customer segments and evaluate the impact of a new store layout on sales performance.

## 📊 Key Tasks Completed

### Task 1: Data Validation & Exploratory Data Analysis (EDA)
- Conducted deep-dive analysis into transaction and purchase behavior data.
- Identified high-value segments: **Mainstream - Young Singles/Couples** and **Mainstream - Retirees**.
- **Key Insight:** Customers show a strong preference for **175g pack sizes** and premium brands like **Kettle** and **Pringles**.

### Task 2: Trial Store Selection & Uplift Analysis
- Developed a benchmarking methodology to match "Trial Stores" with "Control Stores" based on similarity scores.
- Measured sales and customer traffic uplift using Python.
- **Result:** Store 77 achieved a peak sales uplift of **62.3%** during the trial period.

### Task 3: Analytics & Executive Reporting
- Translated technical findings into actionable business insights.
- Structured a professional presentation for the Category Manager using the **Pyramid Principle**.
- Provided recommendations on assortment optimization and regional roll-out strategy.

## 🛠️ Tools & Technologies
- **Python** (Pandas, Matplotlib, Seaborn)
- **Statistical Analysis** (Uplift & Confidence Intervals)
- **Data Visualization**
- **Business Strategy & Reporting**
